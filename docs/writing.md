# 블로그 글쓰기

글쓰기 화면은 이 컴퓨터에서만 열립니다. 공개 사이트의 방문자는 글쓰기 화면이나 초안에 접근할 수 없습니다.

## 열기

`scripts/write-blog.command`를 더블 클릭합니다. 또는 프로젝트 폴더의 터미널에서 `npm run write`를 실행합니다. 안내된 http://127.0.0.1:4320/ 에 접속합니다. 처음 실행할 때 Node.js 20 이상이 필요합니다.

## 작성부터 공개까지

1. 새 글을 만들고 제목, 분류, 날짜, 요약과 본문을 작성합니다. 글 주소는 영문 소문자·숫자·하이픈으로 정합니다. 예: `shinsungin-first-note`.
2. 본문은 일반 텍스트로 입력합니다. 빈 줄을 넣으면 문단이 나뉩니다. HTML이나 마크다운 서식은 실행하지 않습니다.
3. ‘초안 저장’을 누릅니다. 저장한 글은 글 목록에서 다시 열 수 있습니다. ⌘S 또는 Ctrl+S로도 저장합니다.
4. ‘미리보기’로 현재 입력한 내용이 실제 글 화면에 어떻게 보일지 확인합니다. 미리보기는 저장하지 않으므로, 창을 닫기 전에 초안 저장 상태를 확인합니다.
5. 준비된 글은 ‘배포할 글로 등록’을 누릅니다. 확인창에서 승인하면 현재 입력을 저장하고 다음 배포에 포함합니다.
6. 사이트 검사와 공개 ZIP 생성을 마친 뒤 기존 Cloudflare Pages 프로젝트에 배포합니다. 배포가 성공해야 공개 사이트에 반영됩니다.

공개용으로 등록한 글도 편집할 수 있습니다. 편집한 초안을 저장하는 것만으로 기존 공개용 글이 교체되지 않습니다. 내용을 확인하고 다시 공개용으로 등록해야 합니다.

‘배포 대상에서 제외’를 누르면 등록된 내용을 새 초안으로 보관합니다. 운영 사이트의 기존 글은 다음 배포까지 남습니다.

## 파일이 보관되는 곳

- 초안과 보관 자료: `.runtime/writing/`. Git과 공개 빌드에서 제외합니다.
- 공개용으로 등록한 글: `content/posts/`. Git으로 이력을 관리하고 사이트 빌드에 포함합니다.
- 글쓰기 화면: `editor/`. 공개 사이트나 배포 ZIP에 넣지 않습니다.

초안 폴더는 Git이 백업하지 않습니다. 컴퓨터를 바꾸거나 정리할 때는 필요한 초안을 별도로 보관하세요. 비공개 원본 PDF와 검토 자료는 공개용 글이나 자산 폴더로 옮기지 않습니다.

## 배포 명령

```sh
npm run check
npm run package:public
```

검사를 통과한 `.runtime/deploy/flyjung-public.zip`만 기존 `flyjung-kr` 프로젝트에 업로드합니다. 저장소 전체를 업로드하지 않습니다. GitHub push만으로는 자동 배포되지 않습니다.

## 종료

글쓰기 서버를 실행한 터미널에서 Ctrl+C를 누릅니다. 저장한 파일은 남습니다.
