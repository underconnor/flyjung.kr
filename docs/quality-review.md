## 기존 안 유지·별도 시안·로컬 글쓰기 — 2026-10-23

기존 디자인은 활동·수상 구분과 블로그 빈 상태만 소폭 수정했다. 확인된 근무 이력이 없으므로 빈 경력 항목은 표시하지 않는다. 별도 코발트색 시안은 전용 출력과 로컬 미리보기로 분리했고, 세 가지 영어 슬로건을 선택·새로고침하며 비교할 수 있다.

로컬 글쓰기 화면은 새 초안, 저장, 실제 글 스타일 미리보기, 배포 대상 등록·편집·제외를 제공한다. 등록 전 초안은 Git과 공개 빌드에서 제외한다. 원본 내용의 fingerprint와 초안 revision을 확인해 오래된 편집 내용이 새 내용을 덮어쓰지 않도록 했다.

- 로컬 빌드 검사 22개와 공개 빌드 검사 27개 통과. 최종 편집기 수정 후 경계 테스트 8개 재검증.
- 기존 화면 기능 22개와 4페이지×4폭 레이아웃 16개 통과. 루트·본문 배경 일치, 가로 넘침 없음 확인.
- 별도 시안은 4폭×3슬로건 12개 조합, URL·새로고침 복원, 이동 링크, 키보드 건너뛰기, 실제 이미지 로딩 확인.
- 글쓰기는 별도 임시 저장소로 사용자 흐름 25개 통과. 390px·1440px 화면과 미리보기 확인 후 테스트 글·서버·전용 브라우저 정리.
- 공개 ZIP에 편집기·초안·별도 시안이 포함되지 않음을 확인. 실제 공개 글은 추가하지 않았고 운영 배포도 변경하지 않았다.

## 인디고 두 안 비교 — 2026-10-23

인디고 타이포 안(`/`)과 비행기·오리 안(`/flight/`)을 각각 320·390·768·1440px에서 실제 브라우저로 점검했다. 두 안 모두 가로 넘침, 깨진 이미지, 실행 오류, 실패한 자산 요청이 없었다. 모든 앱 이미지를 로드한 상태에서 데스크톱·모바일 전체 화면을 확인했다.

이미지 로드 후 SVG 대체 그림이 함께 보이던 문제를 `hidden` 속성으로 수정했다. 버튼의 키보드 비행, 실행 중 중복 조작 방지, 완료 복원, 움직임 줄이기, 실행 중 설정 변경 시 취소를 확인했다. 건너뛰기 링크와 시안 간 이동도 동작했다. 이전 파랑안은 `/archive/`에서 그대로 열린다.

공개 빌드 경계 검사 5개가 통과했고, 원래 사이트 소스(`site/`, `src/`)에는 변경이 없다. 두 새 시안·캐릭터 그림은 기존 운영 배포에 포함하지 않았다. 검증 기록과 화면은 `.runtime/qa/personal-design-check.txt`, `output/playwright/`에 로컬로 보관한다.

## 별자리·오리·ASCII 개편 — 2026-10-24

별자리 안을 주안으로 두고 깊은 블루, 큰 영어 슬로건, CV 우선 배치를 적용했다. 오리자리는 버튼으로 별을 연결해 찾아보게 했고, ASCII 787 안은 사각 터미널 틀을 제거해 하늘 위 문자 그래픽으로 재배치했다. 명령 입력은 기본적으로 접혀 있다. 독립 WebGL 안과 이전 디자인은 보관한다.

- 미리보기 HTTP·공개 산출물 경계 10개 검사 통과. `.mjs` MIME, 배포 manifest 바이트 일치, 실험안·오리·항공기 모듈 제외 확인.
- 별자리 안은 320·390·768·1440px에서 가로 넘침 없음, 루트/본문 배경 일치, CV→고정 2개→전체 목록 순서를 확인. 별·오리 전환과 복원, 숨긴 링크 포커스 제외, 키보드 이동, 검색·빈 결과·초기화·URL 복원, 움직임 줄이기를 검증했다. 브라우저 오류 0개.
- 새 ASCII 안은 실제 브라우저 검사 34개 통과. 네 화면 폭에서 문자 그래픽이 영역 안에 들어가며 시점·드래그·키보드 회전·초기화, 명령 이력, 프로젝트 열기, 검색·빈 상태·초기화와 문자열 안전 출력을 확인했다. 브라우저 오류 0개.
- 잘못된 `view constructor`·`rotate __proto__` 명령이 상속 속성을 조회하던 오류를 수정하고 재검증했다. 보관 WebGL 안의 시점 선택 범위 오류도 수정했고 실제 WebGL, 4개 시점, 드래그·키보드, 선 표시, 초기화 및 컨텍스트 손실 시 Canvas 대체를 확인했다.
- 신규 프로젝트 이미지 수집을 공통 데이터에 연결했다. 기존/신규 이미지 수집·중복 제거, 잘못된 경로 15개, 파일 누락·심볼릭 링크 거부를 검증했다. 메모리의 가상 콘텐츠로 프로젝트가 세 개여도 고정 영역은 두 개를 유지하고, 등록한 경력과 공개 글을 조건부 표시하는지 확인했다. 실제 콘텐츠는 추가하지 않았다.

최종 데스크톱·모바일 화면은 `output/playwright/night-final-*`, `night-duck-*`, `terminal-night-*`에 보관한다. 원래 공개 사이트 소스와 운영 배포는 변경하지 않았으며 검증용 Chrome 세션만 종료했다.

## 밝은 본문을 더한 두 절충안 — 2026-10-24

기존 시안을 유지하고 `/horizon/`, `/daybreak/`를 추가했다. 두 안 모두 정지원을 주 제목으로 두고 슬로건을 보조 문장으로 낮췄다. A는 밤하늘에서 회청색 본문으로 이어지고, B는 미색 지면 안에 인디고 장면을 배치한다. 별은 실제 기록의 시작 연도나 분류를 나타내며 해당 이력·프로젝트로 연결된다. 새 안에는 오리자리와 장식 점선을 넣지 않았다.

독립 디자인 검토와 실제 캡처 확인 후 A의 모바일 도입부를 압축했다. 390px 화면에서 밝은 CV 시작이 1163px에서 982px로 181px 빨라졌고, 이름과 소개 크기는 유지했다. B의 모바일 연결도는 세 열에서 두 열로 바꾸고 노드 글자를 11–12px로 키워 기관명이 단어 단위로 읽히게 했다.

- 두 안을 320·390·768·1440px에서 확인했다. 가로 넘침·실행 오류가 없고 이름이 슬로건보다 크며 CV→최대 두 고정 프로젝트→검색 목록 순서를 유지한다. A의 별 링크 네 개는 높이 44px이며 서로 겹치지 않는다.
- 검색·빈 상태·초기화, 별에서 실제 프로젝트 상세로 이동, 직접 fragment 진입과 포커스를 확인했다. A의 검색 URL과 상세 hash 충돌을 수정했고, B의 fragment 기록·직접 상세 열기도 수정했다. B는 실제 브라우저 기능 검사 39개를 통과했다.
- 787의 날개·기수·엔진 비율, 기본 카메라와 ASCII 명암을 수정했다. 실제 WebGL, 문자 전환, 시점·키보드·드래그·초기화, 움직임 줄이기, 입력 종료 후 렌더 정지, WebGL 손실 시 문자 대체와 복원을 확인했다. 공유 엔진은 숨긴 장면 정지와 제거 시 자원 정리도 검사했다.
- 뒤로가기 후 장면 복원과 `pagehide.persisted` 보존 분기를 확인했다. 검증 브라우저에서 실제 BFCache hit는 발생하지 않아 BFCache 복원 성공으로 기록하지 않는다.
- 미리보기 HTTP·공개 경계 검사 10개와 JavaScript 구문 검사 7개를 통과했다. 새 빌드 이후 기존 시안 산출물 153개 SHA-256이 모두 일치한다. 공개 사이트 소스와 운영 배포는 그대로다.

최종 화면은 `output/playwright/horizon-final-*`, `daybreak-final-*`에 로컬로 보관한다. 다음 발전안은 밤하늘 색과 의미 있는 별, 밝은 본문의 균형이 더 잘 맞는 A를 우선 추천하되, 두 경로 모두 비교할 수 있게 유지한다.

공통 메뉴는 실제 Chrome에서 12개 경로 모두 목록·현재 선택·Escape 포커스 복귀·390px 넘침·Blog 연결을 확인했고, 실행 오류와 실패 자산 요청이 없었다. 시안 데이터와 운영 소스는 분리하며 공개 미리보기 HTTP·배포 경계 검사 10개도 통과했다. 별에 사용하는 커밋 6개의 SHA·날짜·제목은 실제 Git 기록과 대조했다.

Horizon·Daybreak·Atmosphere·Descent·Orbit는 320·390·768·1440px에서 확인했다. Horizon의 문자 그래프는 키보드와 포인터로 해당 관계를 강조하며, 유휴 시 추가 렌더가 없다. Daybreak 기능 47개, Orbit 기능 24개, Atmosphere 기능 21개, Descent 기능 22개를 통과했다. Atmosphere의 링크·안내 13개를 네 화면 폭의 그라데이션 배경에서 샘플 측정한 대비는 최저 4.66:1, Descent 커밋 기록은 32개 샘플에서 최저 4.75:1이다. Descent의 커밋 별 12개 클릭 검사는 실제 선택 영역과 목적 URL을 확인했으며 외부 GitHub 응답은 검증용 대체 응답을 사용했다. 모든 최종 화면은 이미지 로드를 마친 뒤 직접 확인했다.

실험실은 실제 브라우저에서 네이티브 스크롤 반응, 포인터 추적과 복귀, 비행 기울기, 축 제한, 입력 끄기·유휴 정지, 실제 WebGL, 키보드 즉시 시점 전환, 감도·관성·모드·시점 URL 복원, 잘못된 주소 기본값 복원, 복사 실패 시 선택 가능한 주소, 전체 초기화를 확인했다. 320×568·390×844에서 설정을 실제 클릭할 때 기체가 함께 보이고 설정을 가리지 않으며, 768·1440px에서도 넘침이 없다. 실제 물리 기기의 터치 검증은 수행하지 않았다.

스크린샷과 원시 결과는 `output/playwright/`에 로컬로 보관한다. 독립 시안 폴더가 화면 구성을 소유하고, 실제 콘텐츠·전체 메뉴·787 모형·입력 엔진은 공유한다. 운영 배포와 비공개 자료 공개에는 변경이 없다.

## 분리된 787 비행·밤하늘 별자리 — 2026-10-26

사용자의 연속 피드백에 따라 `/constellation/`, `/sky-trail/`, `/constellation-lab/`을 기존 12개 시안과 분리해 추가했다. 세 안의 첫 화면은 이름과 ASCII 787만 있는 심야 인디고다. 별자리는 비행기와 겹치지 않는 다음 장면에 놓고, 밝은 CV 본문으로 이어진다. 비행기 조작 버튼이나 사용 안내는 새 시안에 없다.

`/sky-trail/`은 787이 별자리 제목에 닿기 전에 사라지고, 검은 별자리 장면 이후 검토한 공개 Git 커밋 세 개를 유성 링크로 지나 밝은 CV에 도착한다. 별의 기본 글은 이름만이며 데스크톱의 hover·키보드 focus에서만 짧은 기간·역할이 나타난다. 모바일의 별을 선택하면 해당 프로젝트 상세 또는 CV 항목으로 이동한다. 원본 자료의 긴 설명은 그곳에서 읽을 수 있다. `/constellation-lab/`의 레이더 원·눈금은 선택형 비교안에만 있고 기본 별자리에는 없다.

실제 Chrome에서 세 새 시안의 320·390·768·1440px 가로 넘침과 별·라벨 겹침을 검사했다. `/constellation/`은 별 링크로 프로젝트 상세와 CV 행에 키보드 이동·포커스가 이어졌고, 787의 스크롤 방위 변화 및 움직임 줄이기 상태의 정지를 확인했다. `/sky-trail/`은 모바일·데스크톱에서 별자리 진입 시 기체 opacity 0, 연결선의 점 중심 정렬, 이름만 보이는 기본 상태, hover/focus의 짧은 정보, 키보드 상세 이동, 커밋 링크 세 개를 확인했다. `/constellation-lab/`은 네 배치의 키보드 선택·URL 복원, hover/focus 관계 강조, 별 링크 이동을 확인했다. 검증 브라우저의 실행 오류는 없었다.

시안 빌드는 15개 경로와 404를 포함한 16페이지를 생성했다. 15개 경로와 HTML에서 참조한 로컬 자산 38개, 공개 Blog를 HTTP 200으로 확인했다. `npm run check:public`은 27/27개 통과했고 공개 묶음에 비교 시안·로컬 글쓰기 파일이 섞이지 않음을 확인했다. axe-core 4.14.0을 실제 Chrome에서 세 새 경로에 실행한 결과 위반 0건이었다. `/constellation/`의 별 링크가 보이는 이름과 접근 가능한 이름이 일치하지 않던 문제는 화면 글을 먼저 읽고 전체 기관명을 숨김 보조 텍스트로 덧붙여 수정한 뒤 재검사했다. 새 시안은 로컬 비교용이며 운영 배포와 최종 디자인 선택은 하지 않았다. 실제 물리 모바일 기기와 스크린리더의 수동 사용성은 이번 점검 범위에 포함되지 않았다.
