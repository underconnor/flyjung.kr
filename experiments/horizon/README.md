# Horizon — 이름에서 시작하는 밤하늘

깊은 파랑의 별자리 상단과 읽기 편한 회청색 하단을 연결한 절충안이다. 기존 밤하늘·ASCII 시안은 보존한다.

## 계획과 검토

- `#090f35` 상단: 정지원 이름을 h1로, Jiwon Jung을 보조 표기로 둔다. 영어 슬로건은 23px 이하로 낮춘다.
- `#edf1f8` 하단: CV → 고정 프로젝트 최대 2개 → 검색 가능한 전체 목록 → 실제 공개 글 순서. 새하얀 면 대신 회청색 바탕과 낮은 대비의 프로젝트 면을 사용한다.
- 별은 실제 이력에 연결한다. 2023 신성인 시작 → 2024 PRON 기장 → 2026 IT지원위원회 PM·모무. 2026년 두 일은 같은 별에 묶어 세부 선후를 만들지 않는다. PRON 활동 시작과 기장 역할 연도를 구분한다.
- 별의 연결선에는 연도순이라는 의미를 부여한다. 점선이나 별도의 비행 항로 장식은 없다.
- 787은 좋아하는 비행기라는 개인 취향을 밝히고 별자리와 분리한다. 작게 조작할 수 있는 ASCII 모형으로 시작하며 문자/입체 전환과 처음 각도 버튼만 제공한다.

```text
정지원 / Jiwon Jung             만든 것과 함께한 일
작은 영어 슬로건                     2024 PRON 기장
짧은 소개                   2023 신성인          2026 IT지원위·모무
작게 조작하는 787                 연도순 연결 설명
───────────────── 밝은 회청색 ─────────────────
CV                       활동 / 수상 / 학력
먼저 볼 프로젝트          신성인 / 모무
전체 프로젝트             검색 + 펼치는 설명
Notes                    실제 공개한 글
```

## 연결과 동작

`renderConcept()`는 `/horizon/`, `/horizon.css`, `/horizon.js`로 연결한다. 공통 catalog 및 CV·blog 데이터를 사용하며 운영 콘텐츠를 복사해 새 원본을 만들지 않는다. 비행기는 공유 `/sky-engine/viewer.mjs`의 `createSkyViewer(host, { mode: 'ascii', interactive: true })`를 사용한다.

연결점은 CSS 배치에 맞춰 ResizeObserver에서 SVG 선만 갱신한다. 별자리에는 반복 애니메이션이 없다. 프로젝트 검색은 NFKC·소문자·공백으로 정규화하고 모든 검색어를 포함한 결과를 보여준다. `?q=`로 검색을 복원하며 Escape와 초기화로 비운다. 고정 프로젝트의 상세 링크는 목록의 해당 details를 열고 이동한다. 검색으로 숨겨진 항목의 별·카드 링크를 누르면 검색을 지운 후 표시한다. 새로고침에서는 기존 상세 hash보다 저장된 검색어를 우선한다.

JavaScript가 없어도 이름·이력·프로젝트·실제 글·기본 링크는 읽을 수 있다. 검색과 비행기 조작만 실행 후 표시한다. 모형 로딩 실패는 해당 영역에 안내하고 본문은 유지한다. 공개 글이 없으면 빈 상태를 정확하게 표시한다.

## 검토 범위

320px부터의 반응형, 명확한 키보드 포커스, 별 링크 최소 44px, 낮은 동작 선호 시 즉시 스크롤을 고려했다. 빌드·실제 브라우저 검사·공유 787 모델 검증은 상위 통합 단계에서 수행한다.
