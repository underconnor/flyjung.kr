# Horizon — 문자로 그린 나의 연결

## 구현 전 계획

이름이 먼저 읽히는 Horizon과 밝은 본문을 유지한다. 상단 별자리는 연도 도표 대신 실제 프로젝트와 활동을 둘러보는 문자 그래프로 바꾼다.

- Night `#090f35`: 이름·비행기·별 그래프 배경.
- Starlight `#c6d0ff`: `*`, `+` 문자 별과 포커스.
- Distant light `#8d9fc9`: 낮은 밝기의 배경 문자와 관계선.
- Paper `#edf1f8`: CV·프로젝트 본문.
- Ink `#182744`, muted `#596781`: 밝은 면의 본문 위계.
- 이름과 본문은 자체 호스팅 Noto Sans KR, 별 문자는 시스템 고정폭 글꼴. 이름 크기는 그대로 두고 영문 슬로건은 17–23px을 유지한다.

```text
정지원 / Jiwon Jung          * 모무
작은 영어 슬로건       * 신성인
소개                              * flyjung
787 문자 모형                + PRON      + IT지원위원회
문자/입체 · 실험실          실제 참여 관계를 잇는 가는 선
──────────────── 밝은 회청색 ────────────────
CV                     활동 / 수상 / 학력
고정 프로젝트 최대 2개 / 전체 검색 목록
footer                 Blog는 주 메뉴에서 직접 이동
```

## 브리프 대조

| Before | After | Why |
| --- | --- | --- |
| 연도 3개를 잇는 삼각형 | 실제 프로젝트·활동이 `flyjung`에 연결된 비대칭 그래프 | 추측한 프로젝트 간 관계 없이 실제 참여만 보여준다. |
| 원형 점 3개뿐인 하늘 | `*`, `+`, `.`의 문자 별과 문자형 노드 | 사용자가 원한 ASCII 별자리 감각을 되살린다. |
| 의미 없는 계속되는 움직임 | 포인터 입력에만 작은 시차, 포커스는 즉시 반영 | 읽기와 조작을 방해하지 않고 유휴 렌더링을 없앤다. |
| 메인의 Notes 빈 상태 | Notes 섹션 삭제, Blog 직접 링크 | 별도 블로그와 메인 콘텐츠의 역할을 명확히 한다. |

## 관계와 동작

`flyjung`은 정지원의 이름표다. 프로젝트 신성인·모무, 활동 PRON·IT지원위원회만 연결하며 표시하는 역할·기간은 공통 catalog/CV 데이터에서 가져온다. 프로젝트끼리의 인과관계나 연도 순서는 만들지 않는다. 노드를 가리키거나 키보드로 포커스하면 해당 관계와 실제 설명이 강조되며, 클릭하면 본문의 정확한 항목으로 이동한다. 고정 프로젝트가 바뀌어도 전체 목록의 상세 항목은 유지된다.

배경 문자 별은 고정된 시드로 배치한다. 자동 반복 애니메이션은 없다. 포인터가 움직일 때만 한 프레임을 요청하고, 동작 줄이기·터치 입력에서는 시차를 끈다. SVG 관계선은 resize에서만 계산한다. 실제 링크와 본문은 JavaScript 없이 읽을 수 있다.

비행기는 공유 `createSkyViewer`를 사용한다. `skyviewerchange`의 ready·mode·renderer 상태로 조작을 동기화하며 bfcache 복원 시 인스턴스를 보존한다. `/flight-lab/`은 더 자세한 항공기 조작으로 이어진다. 공통 비교 내비는 `renderConceptNavigation('horizon')`으로 연결한다.

CV → 고정 최대 2개 → 검색 가능한 전체 목록 순서는 유지한다. 검색은 `?q=`로 복원하고 초기화·Escape를 지원한다. 이전 상세 hash가 남아 있어도 새로고침에서 검색어가 지워지지 않는다. 명시적인 별·카드 링크는 숨겨진 해당 프로젝트를 표시한 뒤 상세를 연다.

## 검증 범위

이 폴더만 수정한다. 운영 사이트·기존 비교안·빌드·Git·배포는 상위 작업에서 관리한다. 통합 후 320/390/768/1440px 배치, 관계선과 글자 겹침, 44px 터치 영역, 실제 fragment, 키보드·검색·모션 감소와 캡처를 확인한다.
