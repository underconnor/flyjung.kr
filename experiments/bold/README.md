# Bold concept

기존 공개 사이트와 별개인 로컬 비교용 시안이다. 사용자가 기존 안을 유지하면서 과감한 안 하나를 비교해 보고 싶다고 요청한 범위에 해당한다. 이 폴더나 `concept-dist/`를 공개 ZIP에 넣지 않는다.

인디고 시안 추가 후에는 http://127.0.0.1:4321/archive/ 에서 이전 파랑안으로 보관한다.

## 방향

- Cobalt `#294acc`: 첫 화면의 큰 색면과 영문 슬로건.
- White `#ffffff`: 읽는 영역과 비교 도구.
- Mint `#c6f4dd`: 모무의 화면을 받치는 넓은 색면.
- Pale blue `#eaf0ff`: 신성인의 실제 화면을 받치는 색면.
- Ink `#17264a`: 밝은 면의 본문.
- 자체 호스팅 Noto Sans KR 400–700을 그대로 쓰고, 타이포 크기와 밀도에서 기존 안과 차이를 만든다.

카드 격자, 장식용 숫자, 가짜 성과 지표 대신 신성인·모무의 실제 앱 화면을 중심에 둔다. 이미지를 잘라내지 않고 원래 비율로 보여준다. 교내 활동과 수상을 별도로 표시하고 확인되지 않은 근무 이력은 추가하지 않는다.

## 슬로건 가안

상단 ‘슬로건 비교’에서 세 문구를 바꿔 볼 수 있다. 선택은 `?slogan=`에 반영되며 새로고침 후 복원된다. 모두 비교용 문구이며 확정된 자기소개나 운영 사이트 문구가 아니다.

- From maybe to made.
- Ideas need a life outside my head.
- Things I make. Things I notice.

## 빌드

```sh
node scripts/build-concept.mjs
```

공통 빌드가 `concept-dist/`에 모든 비교 시안과 보관용 파랑안을 함께 만든다. 명시적으로 허용한 공개 자산과 비행기 시안의 그림만 복사한다. 127.0.0.1 전용 미리보기 서버로 확인한다. ‘기존 안 보기’는 기존 공개 빌드 미리보기 `http://127.0.0.1:4319/`에 연결된다. 프로젝트·CV·블로그 링크는 현재 운영 중인 사이트에 연결된다.

원본 PDF·개인 자료·초안·소스 디렉터리는 복사하지 않는다. 공개용 `npm run package:public` 흐름에는 이 시안이 포함되지 않는다.
