# 787 3D 시안

보관용 시안입니다. 후속 피드백에 따라 주 비교 화면에서는 제외하고 별자리·ASCII 안을 발전시킵니다. 아래 모델과 조작 기능은 비교 기록으로 유지합니다.

사용자가 좋아하는 Boeing 787을 실제로 돌려 볼 수 있는 3D 장면으로 표현한다. 오리와 합친 캐릭터나 정적인 생성 이미지는 쓰지 않는다. 비행 경력을 주장하지 않고 취향과 조작 경험으로 표현한다.

## 계획과 검토

- 밤하늘 `#080c24`, 인디고 `#151c48`, 패널 `#101735`, 밝은 글자 `#f4f5ff`, 별빛 `#c6ccff`, 보조 글자 `#a7afce`.
- 큰 영어 슬로건은 공통 `catalog.mjs`의 `signature`를 그대로 쓴다. Noto Sans KR을 크기와 굵기로 구분하며 기술 수치처럼 보이는 장식은 넣지 않는다.
- 왼쪽 슬로건·이름과 오른쪽 큰 3D 모델을 첫 화면에 놓는다. 모바일에서는 슬로건 다음에 모델이 온다.
- CV(활동·수상·학력)를 먼저 보여 준 뒤, 고정 프로젝트 최대 2개와 전체 프로젝트의 짧은 목록을 둔다.
- 처음의 밝은 인디고 배경 계획은 사용자의 후속 ‘완전히 어두운 밤하늘 인디고’ 요청에 맞춰 폐기했다. 별은 작은 고정 점으로만 사용하며 조작하지 않을 때 장면은 움직이지 않는다.


## 실제 3D

`/aircraft/model.mjs`의 `createAircraft()`에서 삼각형 정점·법선·색상·선분을 받아 WebGL 깊이 버퍼와 조명으로 렌더링한다. PNG를 회전하거나 CSS 원근 효과로 흉내 내지 않는다. 정면·측면·위·사선 시점, 포인터 드래그, 방향키, 확대 범위, 선으로 보기, 초기화를 지원한다.

자동 회전·관성·반복 애니메이션이 없으며 입력과 크기 변경 때만 한 프레임을 그린다. 휠을 가로채지 않는다. DPR을 2로 제한한다. WebGL 사용이 불가능하거나 컨텍스트가 끊기면 같은 3D 좌표의 투영을 2D 선으로 그리며 시점 조작은 계속 작동한다. 모델은 787을 참고한 스타일 스케치이며 공식 CAD 데이터가 아니다.

## 경계

`renderConcept()`를 내보내고 `/hangar.css`, `/hangar.js`를 사용한다. 공개 프로젝트·CV 데이터만 사용하며, 별도 비교 빌드의 `/hangar/`에 연결한다. 운영 배포·편집기·초안에는 영향을 주지 않는다.

전체 프로젝트 목록은 제목·역할·내용을 검색할 수 있다. 결과 수, 결과 없음, 검색 지우기와 Escape 초기화를 제공한다. 공개 카탈로그에서 만든 DOM을 필터하므로 별도 프로젝트 데이터 사본을 유지하지 않는다.
