# 밤하늘

사용자의 밤하늘 인디고·별 취향을 실제 그래픽과 조작으로 표현한 기본 비교 안이다. 큰 영어 문구는 `Somewhere between code and stars.`로 정했다. 그림 파일이나 비행기·오리 합성 이미지는 사용하지 않는다.

## 계획과 검토

- Night `#090f35`: 페이지와 별이 놓이는 깊은 블루 바탕.
- Deep indigo `#101740`: CV 영역을 구분하는 면.
- Indigo `#28326b`: 조작과 연결선의 깊이.
- Starlight `#c6ccff`: 별과 포커스.
- Text `#f4f5ff`, muted `#abb3d4`: 읽는 정보.
- 자체 호스팅 Noto Sans KR. 큰 영어 슬로건을 첫 화면의 중심에 두고 실제 이름·소개를 아래에 놓는다.

```text
flyjung                         CV Projects Notes

Somewhere                       · CV
between code              · Projects
and stars.                       · Notes
정지원 / 소개                별자리 선

CV                      활동 / 수상 / 학력
고정 프로젝트            신성인 / 모무 (최대 2개)
전체 프로젝트            검색 + 펼칠 수 있는 목록
Notes                    기록
```

밝은 라벤더 면을 삭제하고 흰색 슬로건과 차분한 별의 빛을 주인공으로 삼았다. 항공 운항 정보나 실존 별자리 이름처럼 사실로 오해할 수 있는 설정은 사용하지 않는다. 787은 별도 ASCII 시안으로 분리하고, 독립 3D 모델 안은 보관한다.

## 그래픽과 기능

`#night-sky` Canvas는 고정된 시드의 별을 그린다. 자동 반복 애니메이션은 없다. 포인터 움직임에 따른 작은 시차와 CV·Projects·Notes 링크의 포커스에만 다시 그린다. `#connect-stars` 버튼은 별 연결선을 켜고 끈다. 실제 세 링크는 해당 섹션으로 이동한다. 움직임 줄이기 설정에서는 시차도 끈다. Canvas를 사용할 수 없어도 이름·콘텐츠·링크는 남는다.

CV는 프로젝트보다 먼저 나온다. 공통 `experiments/catalog.mjs`의 `pinnedProjects`에서 최대 두 개만 강조하고, 나머지는 `projects` 전체 목록에서 찾는다. `#project-search`는 이름·역할·본문을 정규화해 검색하고 결과를 알린다. 검색 상태는 `?q=`에 남으며 새로고침으로 복원된다. 각 프로젝트는 네이티브 details로 설명을 펼친다. 자바스크립트가 없으면 검색 조작만 숨기고 전체 목록과 details는 그대로 읽을 수 있다.

`renderConcept()` / `/night.css` / `/night.js`로 연결한다. 이 폴더만 수정하며 운영 사이트와 공개 ZIP에는 포함하지 않는다.

`오리자리 찾기`를 누르면 탐색 별 대신 29개의 별이 오리 형태를 만든다. 한 번 더 누르면 섹션 탐색으로 돌아온다. 데이터는 `experiments/duck/constellation.mjs`에 분리하며 별자리 선 토글과 키보드 조작을 지원한다. 오리 표시 중 숨긴 별 링크는 포커스에서 제외하고 상단 주 메뉴를 유지한다. Notes는 실제 공개 글이 있으면 최근 두 개를 표시한다.
