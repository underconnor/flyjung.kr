# 터미널 포트폴리오

사용자가 요청한 개성은 정적인 비행기·오리 합성 그림이 아니라 조작하는 그래픽이다. 787을 참고한 실제 3차원 지오메트리를 문자 격자로 투영하고 명령으로 포트폴리오를 둘러보는 안을 만들었다.

## 계획과 브리프 검토

- 전체 지면은 짙은 파란 밤하늘 `#0a1648`, 별빛 `#ccd6ff`, 본문 `#f3f5ff`, 보조 글자 `#a7b6df`.
- 큰 영어 슬로건과 본문은 자체 호스팅 Noto Sans KR, 터미널 명령·그래픽은 시스템 고정폭 글꼴.
- 초기 밝은 작업창 계획은 사용자의 후속 색 지시에 따라 완전히 어두운 인디고로 변경했다.
- ASCII 자체는 마음에 들지만 터미널 창 구성이 마음에 들지 않는다는 후속 피드백에 따라, 사각 패널을 없애고 문자가 하늘 위에 놓이는 편집형 구성으로 다시 바꿨다. 큰 슬로건 옆에 787과 희미한 별자리·점선 경로를 두고, 명령 콘솔은 기본적으로 접혀 있는 하단 한 줄로 줄였다. 독립 3D 안으로 가는 링크는 뺐다.
- 폴더명·명령·프롬프트는 실제 이동과 조작에 연결된다. 비행 고도·노선·관제 기록처럼 실제 이력으로 오해할 수 있는 가짜 정보는 넣지 않는다.
- 그림과 슬로건을 다시 붙이는 접근 대신 실제 문자 렌더러 하나를 기억에 남는 중심으로 둔다.

```text
Somewhere between          별·점선 경로
code and stars.            3D에서 투영한 787 문자 그래픽
소개                       시점 버튼 / 드래그

❯ 명령으로 둘러보기                            +

CV: 활동 / 수상 / 학력
고정 프로젝트 최대 2개
전체 프로젝트: 간결한 목록
기록
```

## 기능

`help`, `whoami`, `work`, `work shinsungin`, `work momu`, `about`, `view perspective|side|front|top`, `rotate left|right|up|down|reset`, `clear`를 지원한다. 입력은 제한된 포트폴리오 명령이며 시스템 명령을 실행하지 않는다. 기록은 최대 30개, 입력 이력은 최대 100개를 메모리에만 보관한다. 출력은 textContent로 만들고 사용자 입력을 HTML로 실행하지 않는다.

지원 시점과 회전 방향은 `Object.hasOwn`으로 제한하므로 `constructor`, `__proto__` 같은 객체 상속 속성을 명령으로 처리하지 않는다.

시점 버튼, 드래그와 방향키로 787을 회전할 수 있다. 초기화는 Home 키로도 가능하다. 자동 회전·반복 별 애니메이션은 없다. 화면 크기와 사용자 조작 때만 다시 그리며, 탭이 보이지 않을 때는 그리지 않는다. 시스템의 움직임 줄이기는 페이지 이동의 스크롤에도 반영한다.

공통 `/aircraft/model.mjs`의 `createAircraft()`를 읽는다. 삼각형의 깊이와 조명을 문자 밝기로 변환하므로 평면 이미지를 회전시키는 방식이 아니다. 787의 정확한 제작 모델이나 비행 시뮬레이터라고 표시하지 않는다.

CV와 프로젝트는 실제 사이트 데이터를 공유한다. `experiments/catalog.mjs`에서 선택한 프로젝트만 고정 영역에 최대 두 개 표시하며, 전체 프로젝트는 별도 목록으로 늘어난다. 명령을 입력하지 않아도 기본 본문과 프로젝트 접기를 사용할 수 있다.

전체 프로젝트 검색은 제목과 설명을 검색하고 결과 개수·빈 결과·초기화를 제공한다. 확인된 근무 경력이 등록되면 활동과 분리된 경력 영역이 나타난다. 기록은 검증된 공개 글 중 최근 두 개를 정확한 글 주소로 연결하며, 공개 글이 없을 때만 빈 상태를 보여 준다.

`render.mjs`의 `renderConcept()`은 `/terminal.css`, `/terminal.js`를 사용한다. 공개 배포와 원래 사이트는 변경하지 않는다.

## 검증

2026-10-23 실제 브라우저에서 320·390·768·1440px의 문서와 ASCII 폭, 시점 변경과 회전·초기화, 명령 이력, 알 수 없는 명령과 상속 속성 입력, 프로젝트 상세 이동, 검색·빈 결과·초기화를 검사했다. 34개 확인이 통과했고 런타임 오류는 없었다. 320px와 1440px 캡처도 직접 검토했다. 결과는 `output/playwright/terminal-night-check.json`, 캡처는 같은 폴더의 `terminal-night-{320,390,1440}.png`와 `terminal-night-full.png`에 있다. 전용 `flyjung-terminal-qa` 브라우저는 검사 후 닫았다.
