# 별의 항로

`/sky-trail/`은 운영 본안과 다른 시안을 보존한 비교안이다. 처음 화면은 그라데이션 없는 짙은 밤하늘이다. 정지원의 이름과 공유 787 문자 모델이 나오고, 스크롤을 따라 기체가 자세를 바꾸며 화면 아래로 내려간다. 같은 밤하늘의 옆쪽에 고정된 별자리들이 차례로 지나간다. 기체와 별자리는 서로 연결하거나 함께 변형하지 않는다. 조작 버튼이나 사용 안내는 없다.

실제 공개 기록 다섯 개를 기체 옆의 세 별자리로 모았다. 신성인과 모무는 각 프로젝트에서 확인한 기능 점 두 개씩을 주변에 두고 연결한다. 두 프로젝트 사이에는 선을 긋지 않는다. 활동 PRON → AI대학 학생회 → IT지원위원회는 확인된 시작 순서로만 잇는다. 기체와 기록을 잇거나 서로 다른 범주의 인과관계를 암시하는 선은 없다. 점 옆에는 이름만 보인다. 데스크톱에서는 hover·키보드 포커스 시 기간·역할 한 줄이 나타나고, 관련 기능 점이 강조된다. 클릭·터치·키보드로 아래의 해당 기록에 간다. SVG 연결선의 끝은 브라우저에서 실제 점 중심을 측정해 맞춘다.

별자리 이후에는 검토된 공개 커밋 세 개가 유성처럼 밝아지는 구간에 놓인다. 각 유성은 날짜·제목·SHA와 실제 GitHub 커밋 링크를 가진다. 이는 고정 스냅샷이며 새 커밋이 자동 반영되지 않는다. 이어지는 본문은 CV → 최대 두 개의 고정 프로젝트 → 검색 가능한 전체 프로젝트 순서다. Blog는 별도 페이지로 간다.

`prefers-reduced-motion: reduce`에서는 스크롤에 따른 비행기 위치·자세 변화와 선 그리기 전환을 끈다. 별자리 링크는 그대로 사용할 수 있다. 데이터는 `site/data/`, `experiments/catalog.mjs`, `experiments/commit-records.mjs`에서 읽는다. 이 시안은 `concept-dist/`에서만 생성되며 운영 공개 빌드 입력에 포함되지 않는다.

## 브라우저 확인 (2026-10-26)

Playwright 브라우저에서 320·390·768·1440px 가로 넘침 0, 별자리 진입 시 비행기 투명도 0, 스크롤에 따른 문자 기체 변화, 프로젝트 별의 키보드 포커스/Enter로 상세 열기와 포커스 이동을 확인했다. 390·1440px에서는 연결선의 SVG 끝과 실제 점 중심 오차가 0.001% 미만이었다. 390px과 1440px의 밤하늘·별자리·커밋 전환 화면을 캡처했고 콘솔 오류는 없었다. `prefers-reduced-motion: reduce`에서 선 전환이 0초이고 자세 변화가 고정값을 쓰는 코드 분기를 확인했다. 물리 모바일 기기 터치와 외부 GitHub 페이지 응답은 확인하지 않았다.

## 병렬 배치 수정 확인 (2026-10-26)

위 기록은 이전 분리 배치의 점검이다. 현재 안에서는 Chrome 320·390·768·1440px에서 기체가 별자리 오른쪽에 남아 있는 스크롤 화면을 다시 확인했다. 1440px의 스크롤 300→700→1050→1350px에서 기체 화면 y좌표는 150→203→250→290px로 내려갔다. 신성인 hover와 키보드 focus는 관련 기능 점 둘을 강조하고, Enter는 해당 프로젝트 상세를 열어 summary에 포커스를 보냈다. 움직임 줄이기에서는 기체 transform이 없고 기능선 전환은 0초다. 모바일의 물리 터치와 이 변경 뒤 axe 검사는 별도로 하지 않았다.
