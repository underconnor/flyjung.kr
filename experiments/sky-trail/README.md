# 별의 항로

`/sky-trail/`은 운영 본안과 다른 시안을 보존한 비교안이다. 첫 화면은 그라데이션 없는 짙은 밤하늘이고, 아래로 스크롤하면서 대기색을 거쳐 밝은 본문으로 이어진다. 정지원의 이름 아래 오른쪽에 공유 787 문자 모델을 두고, 기체는 스크롤에 따라 자세를 바꾸며 내려간다. 작은곰자리의 국자 형태를 연상시키는 점 별은 첫 화면의 소개 아래 왼쪽에서 시작해 아래로 이어진다. 기체와 별자리는 서로 연결하거나 함께 변형하지 않는다. 조작 버튼이나 사용 안내는 없다.

국자형 점 일곱 개는 형태를 비교하기 위한 장식 별이다. 이름·링크·실제 천체나 이력 의미를 붙이지 않고 보조 기술에서도 숨긴다. 실제 공개 기록 다섯 개는 그 아래 기체 옆의 별자리로 따로 이어진다. 신성인과 모무는 각 프로젝트에서 확인한 기능 점 두 개씩을 주변에 두고 연결한다. 두 프로젝트 사이에는 선을 긋지 않는다. 활동 PRON → AI대학 학생회 → IT지원위원회는 확인된 시작 순서로만 잇는다. 기체와 기록을 잇거나 서로 다른 범주의 인과관계를 암시하는 선은 없다. 점 옆에는 이름만 보인다. 데스크톱에서는 hover·키보드 포커스 시 기간·역할 한 줄이 나타나고, 관련 기능 점이 강조된다. 클릭·터치·키보드로 아래의 해당 기록에 간다. SVG 연결선의 끝은 브라우저에서 실제 점 중심을 측정해 맞춘다.

별자리 이후에는 검토된 공개 커밋 세 개가 유성처럼 밝아지는 구간에 놓인다. 유성의 짧은 꼬리는 화면에 들어올 때 한 번만 비스듬히 아래로 떨어지고, 위로 다시 스크롤해도 되감기지 않는다. 각 유성은 날짜·제목·SHA와 실제 GitHub 커밋 링크를 가진다. 이는 고정 스냅샷이며 새 커밋이 자동 반영되지 않는다. 이어지는 본문은 CV → 최대 두 개의 고정 프로젝트 → 검색 가능한 전체 프로젝트 순서다. Blog는 별도 페이지로 간다.

불규칙하게 흩어진 점 별은 밝기와 크기가 다른 세 깊이 층을 이룬다. 정밀 포인터에서는 깊이마다 최대 2·5·9px의 약한 이동을 주고, 기록 별은 포인터와의 거리에 따라 빛만 달라진다. `prefers-reduced-motion: reduce`에서는 배경·비행기 움직임, 선 그리기와 유성 낙하를 끈다. 별자리와 커밋 링크는 그대로 사용할 수 있다. 데이터는 `site/data/`, `experiments/catalog.mjs`, `experiments/commit-records.mjs`에서 읽는다. 이 시안은 `concept-dist/`에서만 생성되며 운영 공개 빌드 입력에 포함되지 않는다.

## 브라우저 확인 (2026-10-26)

Playwright 브라우저에서 320·390·768·1440px 가로 넘침 0, 별자리 진입 시 비행기 투명도 0, 스크롤에 따른 문자 기체 변화, 프로젝트 별의 키보드 포커스/Enter로 상세 열기와 포커스 이동을 확인했다. 390·1440px에서는 연결선의 SVG 끝과 실제 점 중심 오차가 0.001% 미만이었다. 390px과 1440px의 밤하늘·별자리·커밋 전환 화면을 캡처했고 콘솔 오류는 없었다. `prefers-reduced-motion: reduce`에서 선 전환이 0초이고 자세 변화가 고정값을 쓰는 코드 분기를 확인했다. 물리 모바일 기기 터치와 외부 GitHub 페이지 응답은 확인하지 않았다.

## 병렬 배치 수정 확인 (2026-10-26)

위 기록은 이전 분리 배치의 점검이다. 현재 안에서는 Chrome 320·390·768·1440px에서 기체가 별자리 오른쪽에 남아 있는 스크롤 화면을 다시 확인했다. 1440px의 스크롤 300→700→1050→1350px에서 기체 화면 y좌표는 150→203→250→290px로 내려갔다. 신성인 hover와 키보드 focus는 관련 기능 점 둘을 강조하고, Enter는 해당 프로젝트 상세를 열어 summary에 포커스를 보냈다. 움직임 줄이기에서는 기체 transform이 없고 기능선 전환은 0초다. 모바일의 물리 터치와 이 변경 뒤 axe 검사는 별도로 하지 않았다.

## 첫 화면 별자리·배경·유성 수정 (2026-10-26)

위 브라우저 점검은 수정 전 배치의 기록이다. 이번 수정은 첫 화면에서 보이는 장식 별 일곱 개, 불규칙한 밝기·크기의 배경 점과 거리 기반 포인터 반응, 787의 시작 구도 및 320px 전용 위치 조정, 검은 첫 화면 뒤의 배경 그라데이션, 유성 꼬리의 한 번만 실행되는 짧은 하강을 대상으로 한다. 장식 별은 실제 프로젝트·활동 기록과 구분한다. 최종 폭별 화면·입력 검증 결과는 별도로 기록한다.

## 530px 첫 화면 배치 보정 (2026-10-26)

이전 폭별 점검에는 실제 인앱 브라우저의 530px 구성이 빠져 있었다. 이 폭에서는 소개 글 아래 왼쪽의 첫 장식 점이 화면 y≈453px에, 오른쪽 787 글자가 y≈465px부터 보이도록 시작 위치를 다시 잡았다. 1440px 데스크톱에서는 첫 장식 점이 x≈570/y≈390px, 기체 글자가 오른쪽 y≈370px부터 시작한다. 별자리의 나머지 점과 사실 기록은 아래로 이어지고 기체는 그 옆을 계속 내려간다. 이번 보정 뒤 첫 화면과 스크롤 구간은 Chrome에서 320·390·530·768·1024·1440px로 살펴봤으며 가로 넘침과 눈에 띄는 라벨·기체 겹침은 없었다. 530px에서 스크롤에 따른 기체 하강, 키보드 Enter의 프로젝트 상세 열기·포커스 이동, 움직임 줄이기에서 기체·별 배경 정지도 다시 확인했다.

## 장식 별자리의 시작 높이와 왼쪽 여백 (2026-10-26)

사용자 피드백으로 일곱 장식 점의 첫 별을 더 내리고, 거의 일렬로 내려가던 손잡이를 좌우로 굽혔다. 첫 두 점은 소개 글과 787 사이의 빈 곳에 두고, 나머지 점과 국자 부분이 화면 왼쪽 공간으로 펼쳐지게 했다. 모바일과 태블릿에서는 국자 왼쪽 점을 화면 가장자리에서 안쪽으로 옮겼다. 모바일 국자 밑점도 실제 신성인 기능 별과 따로 읽히도록 높이와 가로 위치를 조정했다. 기록 별, 기체, 페이지 구조와 스크롤 동작은 수정하지 않았다.

시안 재빌드 후 실제 Chrome에서 320·390·530·601·768·801·1100·1101·1440px의 첫 화면을 촬영했다. 첫 장식 별 중심은 530px에서 x≈79/y≈530px, 1440px에서 x≈507/y≈523px이고, 모든 폭에서 가로 넘침은 없었다. 320·530·768·1440px에서는 스크롤 600·1050px 장면을 추가로 보고 별자리 그릇과 아래 기록 별의 분리를 확인했다. 이 기록은 브라우저 화면 검증이며 물리 모바일 터치 검증은 아니다.
