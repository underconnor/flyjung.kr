# Daybreak — 페이지 전체가 밝아오는 하늘

## 설계와 브리프 검토

직사각형 인디고 장면과 미색 지면을 모두 없앤다. 새벽 블루가 페이지 전체에서 옅은 하늘색으로 풀리고, 이름·787·실제 기록의 문자 별이 그 위에 직접 놓인다. 이 안은 기존 밤하늘 안을 밝은 카드에 담은 변형이 아니라 밝아오는 시간 자체를 화면의 배경으로 삼는다.

색은 새벽 블루 `#90b1d7`, 공기색 `#b4cee7`, 아침빛 `#dcecf8`, 가장 밝은 하늘 `#eff7fc`, 글자 `#17375b`, 별빛 `#f7fbff`를 사용한다. 이름과 본문은 자체 호스팅 Noto Sans KR, 787과 별 문자만 고정폭 글꼴을 쓴다. 이름은 가장 큰 위계로 유지하고 영어 슬로건은 18–20px의 보조 문장으로 둔다.

```text
정지원 / Jiwon Jung                 열린 하늘의 ASCII 787
짧은 소개                          문자 / 입체 / 비행실험실

     * 신성인            * IT지원위원회
                * 모무                 * 숭실대학교
     * PRON                * AI대학 학생회

CV
고정 프로젝트 최대 두 개
검색 가능한 전체 프로젝트
```

초기 연결도는 세 분류의 수직 가지 구조였지만 조직도처럼 읽혀 공기감이 부족했다. 이번에는 각 실제 기록을 독립적인 문자 별로 두고 연결선을 제거한다. 분류는 별 옆의 짧은 글자로 명확히 알리고, 클릭하면 실제 프로젝트나 해당 CV 항목으로 이동한다. 없는 활동이나 사건 사이의 관계는 만들지 않는다. 단순 장식 때문에 임의의 숫자나 대문자 눈썹을 붙이지 않는다.

## 상호작용 기준

| Before | After | Why |
| --- | --- | --- |
| 인디고 직사각형 안의 연결도와 비행기 | 전면 하늘 위에 직접 놓인 문자 별과 787 | 새벽이라는 이름과 전체 화면을 연결한다. |
| 분류마다 이어진 수직 연결선 | 분류 글자와 실제 대상 링크 | 관계를 꾸미지 않고 각 기록을 읽을 수 있다. |
| 메인 Notes 빈 상태 | 주메뉴의 Blog 링크 | 비어 있는 섹션으로 페이지를 늘리지 않는다. |
| 키보드로 별을 선택해도 부드러운 스크롤 | 키보드는 즉시 이동, 포인터만 짧은 이동 | 반복 입력에 지연을 만들지 않는다. |

상시 흔들림이나 반짝임은 없다. 화면의 공기감은 색과 여백으로 만든다. 787 조작과 모드 전환은 공통 `createSkyViewer()`를 사용하고, 키보드 즉시 반응·짧은 시점 전환·화면 밖 정지는 엔진의 동작을 따른다. 움직임 줄이기를 적용하며 BFCache 저장 시에는 장면을 파괴하지 않는다.

공통 비교 메뉴는 `renderConceptNavigation('daybreak')`로 넣고 빌더가 공통 스타일과 동작을 제공한다. 주메뉴는 CV, Projects, Blog이며 Blog는 기존 로컬 블로그로 연결한다. 비행실험실은 `/flight-lab/`로 연결한다. 경력·활동 분리, 고정 프로젝트 최대 두 개, 전체 프로젝트 검색과 실제 이미지·내용을 유지한다.

수정 범위는 `experiments/daybreak/`의 네 파일뿐이다. 다른 시안·빌드·Git·공개 배포는 변경하지 않는다.

## 새벽 개편 검증

실제 Chromium 전용 세션에서 47개 검사를 통과했다. 320·390·768·1440px에서 가로 넘침이 없고 이름은 슬로건보다 큰 위계를 유지한다. 실제 별 링크의 프로젝트 열기·CV 이동·포커스·주소 조각, 검색과 빈 결과·초기화, 문자/입체 전환, 시점과 초기화, 키보드 즉시 반응, 움직임 줄이기를 확인했다. 런타임 오류는 없었다.

1440·390·320px 캡처와 모바일 CV 화면을 직접 검토했다. 사각 배경 없이 이름과 787, 별이 하늘 위에 놓이고 아래로 갈수록 배경이 밝아진다. 모바일 별은 2열이며 기관명이 읽히는 줄바꿈을 유지한다. 실제 BFCache 복원은 해당 Chrome 실행에서 발생하지 않아 확정하지 않았다. `persisted: true` pagehide 시 장면 유지와 일반 뒤로가기 후 장면 재생성은 확인했다.

검증 결과는 `output/playwright/daybreak-dawn-check.json`, 화면은 같은 폴더의 `daybreak-dawn-1440.png`, `daybreak-dawn-390.png`, `daybreak-dawn-320.png`, `daybreak-dawn-390-cv.png`에 있다.
