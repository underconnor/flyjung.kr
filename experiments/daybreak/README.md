# Daybreak — 밝은 지면과 한 장의 밤

## 계획과 브리프 검토

기존 두 시안을 유지하면서 이름과 이력이 잘 읽히는 절충안을 만든다. 기본 배경은 따뜻한 미색 `#f7f6f2`, 본문은 `#192037`, 보조 글자는 `#666d7d`다. 인디고 `#131f53`는 연결도와 787이 함께 놓이는 하나의 넓은 면에만 사용한다. 유리 패널, 카드 그리드, 임의의 단계 번호, 대문자 눈썹 문구는 넣지 않는다.

처음에는 이름과 밤 장면을 나란히 두는 구성을 검토했지만, 이름이 가장 먼저 보이고 밝은 공간의 비중이 확실히 달라지도록 밝은 소개 지면 아래에 가로로 넓은 밤 장면을 놓았다. 이름은 데스크톱 84px·작은 모바일 56px, 영어 이름은 26–35px, 슬로건은 16–20px로 낮췄다. 본문과 제목은 기존 자체 호스팅 Noto Sans KR를 사용하고, 일부 짧은 보조 정보만 시스템 고정폭 글꼴로 표시한다.

```text
정지원 / Jiwon Jung                  짧은 소개
Somewhere between code and stars.

[ 한 장의 인디고 밤 ---------------------------------- ]
[ 프로젝트 / 활동 / 학력의 실제 분류       좋아하는 787  ]
[ 각각의 별 → 실제 상세나 CV 항목         문자 / 입체   ]

CV
고정 프로젝트 최대 2개
검색 가능한 전체 프로젝트 목록
최근 공개 글 또는 빈 상태
```

## 의미와 기능

연결도는 실제 프로젝트, 활동, 학력을 분류한 목차다. 선은 각 분류와 그 아래 항목만 연결한다. 비행 경로나 사건 사이의 관계를 임의로 꾸미지 않는다. 각 별은 실제 프로젝트 접기를 열거나 해당 CV 항목으로 이동한다. 프로젝트·CV·공개 글은 기존 공통 데이터에서 읽는다. 확인된 근무 경력이 있을 때만 활동과 구분된 경력 항목을 표시하고, 글은 검증된 공개 글 중 최근 두 개를 정확한 slug로 연결한다.

787은 취향을 담는 작은 장면이며 연결도와 의미를 섞지 않는다. `/sky-engine/viewer.mjs`의 `createSkyViewer()`를 사용한다. 기본은 ASCII이며 같은 장면에서 문자/입체, 입체 시점/옆/위, 초기화를 제공한다. ready 상태에 따라 버튼을 활성화하고, 실제 모드와 카메라 상태에서 `aria-pressed`를 갱신한다. BFCache에 들어가는 `pagehide`에서는 장면을 파괴하지 않는다. 모델 오류가 있어도 나머지 목차와 콘텐츠는 사용할 수 있다.

전체 프로젝트 검색은 제목·설명을 비교하고 결과 개수, 빈 결과, 초기화를 제공한다. 움직임 줄이기 설정은 페이지 내 이동에도 적용한다. 그래픽의 관성·짧은 시점 전환·화면 밖 중지는 공통 엔진에서 처리한다.

## 통합

`render.mjs`에서 `renderConcept()`를 내보낸다. 경로는 `/daybreak/`, 정적 파일은 `/daybreak.css`, `/daybreak.js`다. 공통 엔진과 `/aircraft-v2/model.mjs`, 기존 폰트와 프로젝트 이미지를 함께 제공해야 한다. 기존 시안, 공개 배포, Git 설정은 바꾸지 않는다.
