# 비행기와 오리 시안

사용자가 말한 비행기·오리를 이름 `flyjung`과 함께 보여주는 별도 시안이다. 근무·비행·여행 이력을 추측해 넣지 않고, 기존에 확인한 프로젝트와 교내 활동만 사용한다. 공개 사이트와 기존 파란 시안은 바꾸지 않는다.

## 계획과 검토

- 바탕 `#fbfbff`, 인디고 `#42396c`, 본문 `#282436`, 보조 글자 `#686278`, 라벤더 `#eceaf4`, 오리 부리의 노랑 `#f7d66a`.
- 자체 호스팅 Noto Sans KR을 사용한다. 첫 화면은 영어 선언문 대신 큰 이름과 오리·종이비행기가 담당한다.
- 왼쪽 이름, 오른쪽 그림, 아래 짧은 소개를 놓고 실제 프로젝트 화면을 이어 보여준다. 모바일에서는 이름→그림→소개 순서로 재배치한다.
- 처음의 항공권·여행 기록 모티프는 실제 경력과 혼동될 수 있어 제외했다. 비행기와 오리는 개인적 취향을 표현하는 그림과 작은 사용자 조작으로만 사용한다.

```text
flyjung                 메뉴

flyjung.                오리와 종이비행기
Jiwon Jung              작은 서명 / 한 바퀴 날기

소개                    만든 것부터 보기
실제 프로젝트 화면과 설명
활동 · 수상 · 학력
기록
```

## 자산과 동작

`assets/flight-duck.png`는 전용 빌드에서 `/flight-assets/flight-duck.png`로 복사한다. 투명한 종이비행기·오리 일러스트를 원래 비율로 표시한다. 이미지가 없어도 간단한 선 아이콘으로 내용과 조작을 유지한다.

‘한 바퀴 날기’는 눌렀을 때만 1회 움직인다. 중복 조작을 막고 진행·완료를 알린다. 시스템에서 움직임 줄이기를 선택하면 움직이지 않고 정적인 응답을 제공한다. 자동 반복 애니메이션·마우스 추적·장식 입자는 없다.

`Grounded, mostly.`는 확정 전 작은 서명 가안이다. 첫 화면의 이름이나 실제 소개를 대체하지 않는다.

부모 빌드에서 `/flight/` 페이지, `/flight.css`, `/flight.js`로 연결한다. 공개 빌드·ZIP에는 포함하지 않는다.
