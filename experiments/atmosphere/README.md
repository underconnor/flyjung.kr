# Atmosphere

밤하늘에서 지면으로 내려오듯, 배경의 밀도가 서서히 옅어지는 비교 시안이다. 별과 787은 별도 패널이 아닌 페이지의 하늘에 놓인다.

## 설계

- 색: 심야 `#090f35`, 청색 대기 `#273f79`, 옅은 대기 `#8faacf`, 아침 하늘 `#dce7f3`, 지면 `#eef3f8`, 본문 `#1a2c48`.
- 글꼴: 기존 Noto Sans KR로 이름과 본문을 통일한다. 문자 별과 항공기만 monospace를 사용한다. 이름은 80px, 슬로건은 20px를 기준으로 둔다.
- 배치: `이름 / 떠 있는 787·프로젝트 별 → 옅어지는 하늘 → CV → 고정 두 프로젝트 → 전체 검색 목록`. 이름과 내용은 왼쪽 정렬한다.
- 별은 실제 프로젝트·활동으로 연결한다. 배경 문자 별은 장식이며 접근성 트리에서 제외한다. 관계가 확인되지 않은 연결선을 만들지 않는다.

## 설계 검토

페이지 안에 그림을 넣은 사각형 패널이나 본문 앞의 둥근 경계는 사용하지 않는다. 그라데이션은 카드 장식이 아니라 밤에서 아침으로 이어지는 페이지 전체의 공간이다. 반복 자동 모션과 임의의 숫자·계기판을 배제했다. 블로그는 주 메뉴에서 별도 페이지로 이동한다.

| Before | After | Why |
| --- | --- | --- |
| 어두운 상단과 밝은 본문의 단단한 경계 | 실제 콘텐츠 사이로 대기가 옅어지는 연속 그라데이션 | 하늘에서 아래로 내려오는 느낌 |
| 그림을 둘러싼 패널 | 하늘 위에 직접 놓인 문자 모형과 별 | 사용자가 원한 떠 있는 느낌 유지 |
| 반복 자동 이동 | 항공기는 드래그·버튼 입력에만 반응 | 읽기를 방해하지 않고 취향을 탐색 |

`renderConceptNavigation('atmosphere')`로 전체 시안을 선택한다. 모델은 공유 `createSkyViewer`를 사용하며 이 경로가 별도의 렌더 루프를 추가하지 않는다. 검색은 URL의 `q`에 남기고, 상세 별 링크는 해당 상세를 펼쳐 포커스를 이동한다.
