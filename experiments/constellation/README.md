# 별과 787

Atmosphere의 이름 중심 배치를 유지하면서 Descent 크기의 문자 787을 첫 밤하늘에 놓은 비교 시안이다. 비행기 조작 버튼이나 사용 설명은 두지 않는다. 비행기의 시점은 첫 화면을 스크롤할 때만 짧게 변하고, 별 지도 영역에 들어가면 화면 밖으로 사라진다. 시스템의 움직임 줄이기 설정에서는 시점이 고정된다.

별 지도는 다음 구획에 독립적으로 놓인다. 선이나 원형 계기판을 만들지 않고 실제 기록 다섯 개를 밝은 점과 항상 보이는 이름으로 표시한다. 각 점은 같은 페이지의 프로젝트 상세 또는 CV 활동으로 이동한다. 신성인·PRON은 2023년 시작 기록, AI대학 학생회·모무·IT지원위원회는 2026년 시작 기록이다. 같은 연도 안의 상대 위치는 시간 순서나 인과관계를 뜻하지 않는다. 주변의 작은 점은 밤하늘의 시각적 질감일 뿐 기록 수를 뜻하지 않는다.

이름·역할·기간은 `site/data/projects.mjs`와 `site/data/cv.mjs`에서 가져온다. 연도별 배치는 시작 연도가 바뀌면 빌드에서 검토가 필요하도록 확인한다. 본문은 CV → 고정 프로젝트 최대 두 개 → 검색 가능한 전체 목록 순서다. Blog는 별도 공개 페이지로 연결한다. 기존 운영 본안과 다른 시안은 이 폴더의 작업으로 변경하지 않는다.

키보드 포커스와 마우스 hover는 점의 빛과 이름의 밑줄을 강조한다. 모바일에서도 이름과 날짜가 보이고 링크의 높이는 최소 48px이다. 비행기는 키보드 포커스를 받지 않는 비대화형 장면이다.

## 2026-10-26 로컬 확인

Chrome에서 320·390·768·1440px 화면의 가로 넘침과 별 링크 간 겹침이 없고, 다섯 링크의 높이가 모두 48px 이상임을 확인했다. 첫 화면의 기체는 별 지도 시작 전에 끝난다. 1440px에서 스크롤에 따라 기체 방위각이 `0.4200→0.4557`로 바뀌었고, 움직임 줄이기에서는 스크롤 후에도 `0.4200`으로 고정됐다. 키보드 Enter로 신성인 별을 선택하면 프로젝트 상세가 열리고 요약에 포커스가 이동하며, AI대학 학생회 별은 해당 CV 활동에 포커스가 이동했다. 별 hover의 점광 변화, 키보드 포커스 테두리, 콘솔 오류 0건과 실패한 로컬 요청 0건을 확인했다. 물리 모바일 기기의 터치 반응은 아직 확인하지 않았다.

화면 기록은 로컬 `output/playwright/constellation-final-{desktop,mobile}-{hero,map}.png`에 보관한다.
