# Descent

이름과 밤하늘에서 출발해 실제 작업의 별을 지나, 밝은 지면의 이력과 프로젝트로 내려오는 안이다. `/descent/`에서 비교한다.

## 시각 계획

- 색: 심야 `#080f32`, 높은 하늘 `#14255a`, 새벽 `#566f9f`, 낮은 하늘 `#b9cde3`, 지면 `#eef3f8`, 본문 잉크 `#1b2c46`.
- 글자: 본문과 이름은 기존 Noto Sans KR. 문자 별과 커밋 해시는 시스템 monospace. 이름 84px, 슬로건 20px로 계층을 분명히 한다.
- 배치: 이름은 왼쪽 위, 비행기는 열린 하늘 중심, 실제 커밋 별은 서로 다른 높이에 놓는다. 지면은 CV → 고정 프로젝트 두 개 → 전체 목록으로 이어진다.
- 짧은 비행 구간에서 기체가 스크롤을 따라 머물며 별을 통과한다. 스크롤 자체는 브라우저 기본 동작을 따른다. 박스·계기판·점선 경로는 만들지 않는다.

```text
정지원                 * 신성인
작은 슬로건        + 모무

       * 커밋      ASCII 787
                       * 커밋
    * 커밋
          푸른 하늘이 밝아짐
CV                         활동
고정 프로젝트              전체 목록
```

초기 계획에서 별마다 카드나 긴 설명을 붙이는 안은 제외했다. 실제 별은 짧은 커밋 해시와 기록으로, 나머지 문자 별은 의미를 주장하지 않는 배경으로 둔다. 블로그는 주 메뉴에서 바로 연다.

## 동작

`/sky-engine/viewer.mjs`의 같은 787 장면을 사용한다. 스크롤에 따른 기준각에 사용자의 드래그 차이를 유지하며 더한다. 스크롤 반응을 끄면 기체 회전과 배경 깊이 이동을 멈춘다. 움직임 감소 환경과 모바일에서는 기체를 화면에 고정하지 않고 기록과 함께 자연스럽게 지나가도록 한다. 마우스 휠이나 터치의 기본 스크롤은 막지 않는다. 유휴 상태에는 렌더 반복을 돌리지 않는다.

커밋은 `experiments/commit-records.mjs`의 실제 이 사이트 저장소 기록 중 세 개다. 날짜나 활동량을 임의로 생성하지 않는다. 프로젝트·이력도 공통 공개 데이터에서 읽는다.

## 실제 화면 검토

| Before | After | Why |
| --- | --- | --- |
| 모바일에서 고정된 기체와 커밋 글자 겹침 | 작은 화면에서는 기체 고정 추적을 해제 | 기록을 가리지 않고 자연스럽게 스크롤 |
| 낮은 하늘에서 밝은 기체 조작 글자가 흐림 | 실제 장면 깊이에 따라 조작 글자와 기체의 명암 전환 | 그라데이션 위에서도 조작이 읽히도록 유지 |
| 그라데이션 중간의 커밋 날짜·본문 대비 부족 | 커밋별 명암 조정과 모바일 두 번째 기록 위치 보정 | 측정한 커밋 글자 대비를 4.5:1 이상으로 확보 |
| 투명한 기체 영역이 커밋 별 클릭을 가림 | 커밋 링크 레이어를 기체 위로 배치 | 별의 실제 클릭 영역을 유지하고 나머지 공간은 드래그에 사용 |

## 최종 검증 — 2026-10-25

320·390·768·1440px Chrome에서 가로 넘침과 실패한 이미지가 없고, 모바일에서 기체와 커밋 기록이 겹치지 않는다. 전체 이미지를 로드한 데스크톱·모바일 화면 및 하강 중간 화면을 직접 확인했다.

스크롤과 드래그 편차 합성, 스크롤 반응 켜기·끄기, 시스템 움직임 감소, 유휴 렌더 정지, 문자·실제 WebGL, 검색·URL 복원·상세 이동 등 핵심 기능 22개를 통과했다. 네 너비에서 커밋 별 12개를 실제로 눌러 새 탭의 목적 URL과 그 뒤의 기체 드래그를 확인했다. 이 클릭 검증은 GitHub 네트워크 응답을 로컬 응답으로 대체했으며, 링크 대상은 실제 저장소 기록과 일치한다.

스크롤 중간 캡처의 실제 배경 픽셀과 CSS 글자색으로 측정한 커밋 텍스트 32개 표본의 최소 대비는 4.75:1이다. 기록은 `output/playwright/descent-final-contrast.json`, 최종 캡처는 `descent-final-{320,390,768,1440}-{full,mid}.png`에 로컬로 보관한다. 물리적 모바일 기기의 터치 동작은 이번 검증에 포함하지 않았다.
