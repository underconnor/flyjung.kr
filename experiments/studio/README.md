# 이름으로 시작하는 안

공개 사이트를 유지한 채 색과 첫인상을 비교하는 로컬 시안이다. 기존 코발트 시안은 바꾸지 않는다.

## 계획

- White `#ffffff`: 문서 전체의 바탕.
- Silver `#f2f2f6`: 비교 메뉴와 모무 화면을 받치는 면.
- Charcoal `#252629`: 제목과 본문.
- Grey `#65676d`: 보조 설명과 날짜.
- Indigo `#42396c`: 사용자 취향에 맞춘 큰 이름, 내비게이션 표시와 선택 색.
- Lavender `#e9e7f4`: 신성인의 실제 앱 화면을 받치는 면.
- Noto Sans KR: 이름에는 크게, 설명에는 편안하게 같은 글꼴을 사용한다. 가짜 영문 슬로건 대신 Jiwon Jung이라는 이름이 첫 화면의 중심이다.

배치는 넓은 이름 → 짧은 소개 → 두 프로젝트의 실제 화면 → 활동과 수상 순서다. 본문은 왼쪽으로 정렬하고, 데스크톱에서는 프로젝트 설명 옆에 두 화면을 나란히 보여준다. 모바일은 설명 다음에 화면을 배치한다.

```text
flyjung                         만든 것  활동  기록

Jiwon Jung.
정지원입니다.                 기획하고, 직접 만듭니다.

신성인 / 역할                 실제 앱 화면   실제 앱 화면
MOMU / 참여                   실제 앱 화면   실제 앱 화면

학교에서 함께한 일             활동 목록
                              수상

기록                          블로그
```

## 브리프에 비춰 고친 점

색만 바꾸고 추상적인 영어 문구를 남기면 사용자가 거절한 인상이 유지된다. 따라서 큰 슬로건을 이름으로 교체하고, 개인의 실제 활동과 작업이 바로 이어지게 했다. 사용자가 후속 답변에서 인디고를 선호한다고 알려 주어, 전면 코발트 면을 딥 인디고 타이포와 연라벤더 이미지 배경으로 바꿨다. 전면 검정·강한 포인트색, 테두리 카드 격자, 장식용 숫자를 쓰지 않는다. 오리·비행기라는 더 직접적인 취향은 별도 `/flight/` 안에서 비교한다.

## 경계

`render.mjs`는 `renderConcept()`를 내보낸다. CSS·JS 요청 경로는 `/studio.css`, `/studio.js`다. 공개 프로젝트/CV 데이터와 허용된 자체 호스팅 글꼴·앱 화면만 재사용한다. 편집기, 초안, 비공개 자료는 읽거나 복사하지 않는다. 공개 배포 변경은 없다.

## 동작

비교 메뉴는 색상 수정안(`/`), 비행기와 오리(`/flight/`), 이전 파랑안(`/archive/`), 기존 공개본 미리보기로 연결된다. 프로젝트 상세, CV, 블로그는 현재 공개 사이트에 연결한다. 자바스크립트가 없어도 모든 콘텐츠와 링크를 사용할 수 있다. 건너뛰기 링크, 포커스 표시, 모션 감소 환경을 지원한다.
