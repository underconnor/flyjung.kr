# 별자리 실험실

운영 본안과 별개인 로컬 비교 화면이다. 첫 화면은 정지원의 이름과 조작 UI 없는 문자 787만 담는다. 별자리 차트는 그 다음 독립 구간에 놓여 비행기와 겹치지 않는다. 차트 뒤에서 밤하늘이 밝은 CV 본문으로 바뀐다.

선택지는 별자리에서 보이는 **기록의 범위와 표현**을 비교한다.

- **두 프로젝트**: 고정 프로젝트 신성인과 모무, 각 프로젝트 자료에 확인된 기능·화면을 작은 점으로 펼친다.
- **프로젝트와 활동**: 위에 IT지원위원회와 PRON을 추가한다. 기본값이다.
- **넓은 기록**: AI대학 학생회와 SSU Bug Bounty 수상을 추가한다.
- **레이더**: 검증된 여섯 상위 기록을 동심원과 정적인 방위선 위의 점으로 표시한다. 원의 거리와 방위에는 실제 측정값을 부여하지 않는다.

프로젝트 점에서 기능 점으로 뻗는 선은 `site/data/projects.mjs`의 직접 만든 부분과 주요 화면에 근거한다. 활동 점끼리는 CV의 활동 범위를 나타내는 별도 선으로 묶는다. 수상은 관계가 확인되지 않아 독립된 점으로 둔다. 각 점은 아래의 해당 프로젝트·활동·수상 기록으로 이동한다. 화면에는 비행기 조작 버튼이나 안내문을 두지 않는다.

`?sky=sparse`, 기본 `?sky` 없음, `?sky=wide`, `?sky=radar`로 비교 상태를 복원한다. 프로젝트 검색은 `?q=`를 따로 유지한다. 모바일에서는 글자가 겹치지 않도록 프로젝트당 작은 기능 점 하나씩만 보여준다. 레이더의 스윕은 정적이어서 지속적인 움직임이 없다.
